# Tagging Prompt

Tags are **not** generated by any script. They are assigned by asking a generic
AI assistant (ChatGPT, Claude, Gemini, a local model…) with the prompt below and
pasting the answer back into `src/videos.json`.

`update_videos.py` never invents tags: it only carries over the ones already in
the JSON, matched by `videoId`.

---

## Workflow

1. Pick the videos you want to tag (usually the ones with `"tags": []`).
2. Copy the prompt below into any AI chat.
3. Paste the video objects you want tagged, in batches of ~25 (the `videoId`,
   `title` and `description` are all the model needs).
4. Copy the JSON array it returns.
5. Apply the result to `src/videos.json` — for each returned object, replace the
   `"tags": []` array of the matching `videoId` with the returned `tags`.
6. Run `python update_videos.py` once you are done: it re-fetches YouTube data,
   keeps your tags by `videoId`, and recomputes `needs_review` for you.

> `needs_review` is derived automatically (`true` when `tags` is empty). You do
> not need to edit it by hand.

To list the videos that still need tags:

```bash
cd be
./.venv/bin/python -c "import json; [print(v['videoId'], '-', v['title']) for v in json.load(open('../src/videos.json')) if not v['tags']]"
```

## The prompt

Copy everything between the markers.

<!-- PROMPT START -->

You are tagging painting-tutorial videos for a Warhammer hobby website. Each
video is a YouTube tutorial (or a video about painting products, models or
techniques). Your job is to assign tags from a fixed vocabulary.

### Input

You will receive a JSON array of videos, each with `videoId`, `title` and
`description`.

### Rules

- Use ONLY the tags from the vocabulary below. Do not invent new tags, do not
  change their spelling, casing or punctuation.
- All tags are lowercase. Tags containing `&` keep the `&` exactly as written
  (e.g. `orks & orruks`, `textures & materials`).
- Assign between 1 and 5 tags per video. Prefer 2 or 3.
- Always add the **parent tags** listed under "Parent tags" in addition to the
  specific tag. For example, a Salamanders video gets `salamanders`,
  `space marines` and `40k`.
- Judge what is being **painted**, not which paints are listed. Paint names are
  a common trap:
  - "Liberator Gold" is a paint, not a Stormcast Eternals video.
  - "Dryad Bark" is a paint, not a Sylvaneth video.
  - "Black Legion" and "Black Templar" are also Contrast paint names.
  - "White Scar" is a paint, not White Scars.
  Only tag the faction if the video is actually about painting that faction.
- Announcements, interviews, product hype, trailers and channel news that
  contain no painting instruction should get only the closest topic tag (or an
  empty array if nothing fits).
- If the video covers several systems or factions, tag all of them.
- Use `beginner`, `intermediate` or `advanced` only when the video's difficulty
  is evident from the title or description.

### Vocabulary

Game systems:
`40k`, `aos`, `horus heresy`, `kill team`, `necromunda`, `old world`,
`underworlds`, `warcry`, `legions imperialis`, `aeronautica imperialis`,
`blood bowl`

Imperium:
`space marines`, `ultramarines`, `blood angels`, `dark angels`, `space wolves`,
`imperial fists`, `salamanders`, `raven guard`, `black templars`,
`astra militarum`, `sororitas`

Chaos:
`chaos`, `chaos space marines`, `world eaters`, `death guard`, `thousand sons`,
`emperor's children`

Xenos:
`tyranids`, `necrons`, `tau`, `eldar`

Age of Sigmar:
`stormcast eternals`, `cities of sigmar`, `sylvaneth`, `seraphon`,
`soulblight gravelords`, `skaven`

Cross-system:
`orks & orruks`

Difficulty:
`beginner`, `intermediate`, `advanced`

Technique and products:
`painting essentials`, `citadel products`, `contrast paints`

Effects and style:
`nmm`, `weathering`

Subject matter:
`bases`, `metal`, `skin`, `cloth`, `textures & materials`, `vehicles`, `scenery`

### Parent tags

Add the parent tags whenever you use the specific tag.

| Tag | Also add |
| --- | --- |
| `space marines` | `40k` |
| `ultramarines`, `blood angels`, `dark angels`, `space wolves`, `imperial fists`, `salamanders`, `raven guard`, `black templars` | `space marines`, `40k` |
| `chaos space marines` | `chaos`, `40k` |
| `world eaters`, `death guard`, `thousand sons`, `emperor's children` | `chaos space marines`, `chaos`, `40k` |
| `tyranids`, `necrons`, `tau`, `eldar`, `astra militarum`, `sororitas` | `40k` |
| `orks & orruks` | `40k`, `aos` |
| `stormcast eternals`, `cities of sigmar`, `sylvaneth`, `seraphon`, `soulblight gravelords`, `skaven` | `aos` |
| `kill team`, `necromunda`, `horus heresy`, `legions imperialis`, `aeronautica imperialis`, `old world`, `underworlds`, `warcry`, `blood bowl` | *(no parent — they are their own system)* |

Chaos legions painted for the Horus Heresy era also get `horus heresy` in
addition to the 40k parents.

### Output

Return ONLY a valid JSON array. No prose, no markdown fences, no comments:

```json
[
  { "videoId": "abc123", "tags": ["salamanders", "space marines", "40k", "beginner"] }
]
```

Every `videoId` you were given must appear exactly once in the output.

### Example

Input:

```json
[
  {
    "videoId": "4eCV5wG8tVc",
    "title": "How to Paint Sylvaneth Soulpods | Grove Guardian | Warhammer Age of Sigmar",
    "description": "In today's video, Ollie's showing you how to paint the unique soulpods of the Grove Guardian model... Paints used: Screamer Pink, Dechala Lilac, Carroburg Crimson."
  }
]
```

Output:

```json
[{ "videoId": "4eCV5wG8tVc", "tags": ["aos", "bases", "sylvaneth"] }]
```

Note how "Screamer Pink" and "Dechala Lilac" are paints and produce no tags.

<!-- PROMPT END -->

## Adding a new tag

The vocabulary above is the contract. If you need a new tag:

1. Add it to the vocabulary list in the prompt (and to the parent table if it
   belongs to a faction or system).
2. Start using it in `src/videos.json`.
3. Keep it lowercase and hyphen/space consistent with the existing tags.

Because the site builds its tag filter from the data, a tag only appears in the
sidebar once at least one video uses it.
