# Warhammer Minus

A fan-made web app to browse and filter Warhammer painting tutorial videos from a curated set of Warhammer YouTube channels. Search by title, filter by channel or by tags like `#40k`, `#aos`, `#beginner`, `#skin`, and more.

🔗 **Live:** [https://rassell.github.io/warhammer-minus/](https://rassell.github.io/warhammer-minus/)

## Tech Stack

- **React 19** + **TypeScript**
- **Vite 8** (build tool)
- **Tailwind CSS 4** (styling)
- **React Router 7** (routing)
- **Lucide React** (icons)
- Deployed on **GitHub Pages**

## Getting Started

```bash
# Install dependencies
yarn install

# Start dev server
yarn dev

# Build for production
yarn build

# Preview production build
yarn preview

# Type check
yarn typecheck
```

## Data Pipeline

The video catalog is generated by `be/update_videos.py`: it fetches every channel
listed in `be/channels.json`, filters the uploads and writes `src/videos.json`,
which is bundled with the frontend.

The script never invents tags. It only carries over the tags that are already in
`src/videos.json` (matched by `videoId`), so re-running it never loses manual work.
The previous file is backed up to `src/videos.json.bak`, and the run finishes by
listing the videos that are new since the last update - those are the only ones
left without tags.

```bash
npm run videos:update              # from the repo root, no venv activation needed

cd be
source .venv/bin/activate
python update_videos.py            # fetch + keep existing tags + save
python update_videos.py --list-channels
```

### Channels

The source channels are configured in `be/channels.json`. Each entry accepts either a channel `id` or a `handle`, an optional `query` (title/description keyword filter, `null` disables it) and an `enabled` flag:

```json
{
  "channels": [
    { "id": "UCwdh3MTrFq3sXlB4ct8B-Fg", "label": "Warhammer (official)", "query": "paint", "enabled": true },
    { "handle": "@JOSEDAVINCI_", "label": "Jose Davinci", "query": null, "enabled": true }
  ]
}
```

Channel-specific exclusion patterns live under `channels` in `be/exclude_patterns.json`; patterns in `global` apply to every channel.

### Short videos

YouTube Shorts and other clips are not tutorials, so any video whose duration is
at or below `short_video_max_seconds` (in `be/exclude_patterns.json`, default `60`)
is dropped while filtering. Titles containing `#short`/`#shorts` are excluded too.
Unknown durations are always kept, and `0` disables the duration filter:

```bash
python update_videos.py --shorts-max-seconds 0    # keep shorts
python update_videos.py --shorts-max-seconds 90   # stricter one-off filter
```

```bash
python update_videos.py --list-channels        # resolve IDs/handles and print them
python update_videos.py --channel @SomePainter # one-off override (repeatable)
```

### Tags

Tags are assigned **manually**, with the help of a generic AI assistant — there is
no tagging code and no API key for it.

1. Copy the prompt from `be/TAGGING_PROMPT.md` into any AI chat
2. Paste a batch of videos (`videoId`, `title`, `description`)
3. Paste the returned JSON back into `src/videos.json`, replacing the `"tags": []`
   of the matching `videoId`
4. Re-run `npm run videos:update` to keep those tags; the summary lists any video
   that is still new

The prompt carries the canonical vocabulary, the parent-tag rules (e.g.
`salamanders` → `space marines` + `40k`) and the expected output format. Videos
without tags simply have `"tags": []`; the tag filter in the sidebar is built from
whatever tags the data contains.

See [`be/TAGGING_PROMPT.md`](be/TAGGING_PROMPT.md) for the prompt and workflow.
